- **線上（每日自動更新）**：https://timchang1977o-maker.github.io/yuanta-funds/

## 本機執行
```bash
python3 build.py     # 只用 Python 內建庫，無需安裝套件
```
產生 `元大基金淨值與表現.html`（自含、離線可看）。

非投資建議；實際淨值以各機構公告為準。
