### 台股基金比較（多多 vs 經貿 vs 台優龍）
頁面中段另有三檔台股基金比較區：元大投信官方 `FuncId=FundNAV` 成立以來逐日淨值自算累積報酬（YTD／1／3／6 月、1／3／5 年、2020/3/23 共同起點）、近 1 年年化波動、近 1／3 年最大回撤、近 1 年高低點；基本資料與理柏月底報酬取自 `FuncId=FundList`。多線報酬指數圖可切區間。

## 本機執行

```bash
python3 build.py     # 只用 Python 內建庫，無需安裝套件
```

非投資建議；實際淨值以各機構公告為準。
